This is a repository storing input data, analytical code, and output data/figures for the paper 'A geometric morphometric approach to identifying extant and fossil woodrat molars with remarks on late Pleistocene _Neotoma macrotis_ from Rancho La Brea', by Nathaniel Fox and Jessica Blois, published in Quaternary Research: https://doi.org/10.1017/qua.2025.9
Specimen images and landmark coordinate data are available at Zenodo: https://doi.org/10.5281/zenodo.15127876
